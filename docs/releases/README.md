# Release notes

Per-release notes used to live here as one file per version. They duplicated the
release entries word-for-word, so they have been consolidated.

- For a one-line summary of each recent release, see [`CHANGELOG.md`](../../CHANGELOG.md).
- For the full per-release rationale — constraints, rejected alternatives, and the
  validation that was run — see [`docs/decisions/decision-log.md`](../decisions/decision-log.md).

Older per-release note files remain recoverable from git history.
