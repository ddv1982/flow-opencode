# Automatic continuation

`flow_status` adds process-local information without Session v5 state or authority.

- `autoContinuation` reports observed request-attribution support. Unknown support is omitted.
- `autoDrive` reports the requesting host session's active, waiting, paused, or inactive state and reason.
- `autoTiming` appears only in detail. It measures the latest invocation's wall time in active work or recognized user checkpoints. Paused time is excluded. It resets on reload and does not measure CPU or coding time.

Owned validation and review preparation continue after authenticated progress.
Receipts retain the exact native assistant and call, capture, source, and named results. Stale evidence
and required failures without an eligible prerequisite repair pause. Same-goal
reversible repairs have no amendment count limit; each accepted amendment permits
one repair handoff. Complete failed inspection observations can reach review.
Unchanged revisions never repeat a prompt. Automatic compaction preserves a lease
only through its exact checked native control record. Real input or manual
compaction of automatic work revokes that interval. Interrupted ordinary history
can summarize without restoring execution authority. Restart discards the lease.
