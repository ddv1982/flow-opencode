# JEV-2 disabled-mode idle-routing diagnostic

This fixed-input probe compares `AutoDriveCoordinator.onIdle` at the JEV-2 PR base `65b3136633068cf05e47276c8c83e68e12ab849e` and head `4644bef8bf53b3fed2e6be3798f39c09eb2a2b5d`. It warms each process, then times 1,500 calls per route with setup outside the timed interval. Both runs use the same four projections: no lease, ready continuation, blocked handback, and inactive. The head receives a real inactive `RecoveryController` with a provider spy; the base has no recovery controller. A fetch guard rejects direct fetches during the replay. All route/read/prompt counts match and both provider and fetch counters are zero.

The nearest-rank p95 increase is at most 0.407 microseconds across the four routes, below the proposed 5 ms disabled-mode limit in this in-memory replay. The head's process RSS after imports is 44.50 MiB versus 28.78 MiB at the base; after the probe it is 70.22 versus 59.66 MiB. These snapshots include module loading and process variation.
