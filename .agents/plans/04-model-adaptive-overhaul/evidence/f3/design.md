# F3 experiment boundary

## Preserve historical interpretation

The existing paired protocol is Flow versus ordinary OpenCode. Reveal checks
bind baseline to the ordinary artifact. Its within-task bootstrap conditions on
the selected fixed tasks. Preserve historical plan hashes, decoders, and analysis
versions. A new plan records its arm specifications and sampling purpose.

## Bind each arm before allocation

Each arm needs an immutable artifact identity or ordinary OpenCode identity,
actual package version, pinned host version, requested manager and reviewer model
settings, and configuration digest. Allocation maps opaque tokens to these
specifications. Neither a Flow artifact nor a model profile is inferred from the
word candidate. Verify every attempt against its selected specification.

A declared comparison changes one factor at a time. Whole-workflow model changes
are explicit total-effect comparisons. Paired inputs and resource limits remain
comparable. Store both Flow artifacts by digest and use each artifact's actual
package version in the host cache. Do not load two versions through one cache
entry based on the current checkout's package.json.

## Declare the study purpose and resource budget

Smoke proves exercised integration. Exploratory studies diagnose failures and
estimate variation. Confirmatory studies require a frozen sample, stopping rule,
qualified graders, and untouched tasks. Preserve the existing conservative
power rule for the historical method. Smaller exploratory studies do not gain a
confirmatory success claim.

Record maximum attempts, wall time, output tokens, known cost, and the treatment
of unknown cost. Validate budget coverage before dispatch. A dry run prints
primary and reserve pair counts and immutable inputs without calling a provider.
Credential entitlement is a bounded, explicitly requested probe, not a plugin
startup side effect.

## Keep task variation visible

The retained task-resampling probe has two tasks and 100 repeated identical
pairs per task. One task always favors each arm. Existing within-task resampling
reports estimate zero with interval [0, 0]. This is a conditional fixed-task
result, not uncertainty across a task population.

A new exploratory interval resamples whole task groups and preserves each
pair. Equal task weights prevent repeated easy tasks from dominating. Its
implementation version, seed, distinct task count, and complete-pair coverage
belong in the frozen analysis. Validate endpoint cases, reproducibility, and
invariance to duplicating identical repetitions. Do not silently relabel it as
a powered confirmatory procedure.

## Dependencies

F1 supplies retained outcomes, oracle controls, and the development corpus.
F2 supplies native variant propagation and structured host observations. F3
implementation starts after those local checks pass. Model campaigns and final
qualification retain their separate budget and evidence gates.
