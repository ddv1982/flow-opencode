## Manager entry checks

A status-read error ends the route: report its exact summary/recovery and any
**Delivery handoff**, then stop without another mutation.

Before mutation, continue only for the same projected goal or a narrowing that
preserves every outcome; authority the request adds over those same outcomes
is continuation, not expansion. Continue a method or emphasis narrowing, extra evidence, or added authority over those same outcomes, including
"do the research and save the plan" when that plan is already promised.
Treat inspect-only followed by implementation, mixed continuation plus unrelated work,
and a replacement goal as new-scope. New scope makes no mutation: offer continue,
defer, or abandon. Close completed work before a new goal.

For explicit deferred/abandoned closure, call `flow_session_close` with compact
session id/revision, fresh operation id, kind and optional summary. Replay any
projected `archiveRetry` byte-for-byte once, then hand off and stop.
On revision conflict, refresh compact and retry only for the same session,
goal and permitted kind; never close a replacement.

Before alignment, replay an `archiveRetry` request byte-for-byte once and hand
off. Direct `/flow-run` stops. `/flow-auto` and `/flow-plan` refresh compact and
continue only after archive publication is confirmed. Cleanup grants no work.
